The book and the tooling

Personal projects, built with AI assistance, with fictional examples. Separate from my employment work. I wrote and coded them to think through how service design methods hold up when AI agents do the first draft, and to learn what it takes to ship a tool.

The book

The Agentic Service Designer, second edition. Service design foundations, methods at machine scale, and an operating model for running the practice with agents and human gates. Free to read online or download as PDF and EPUB. The worked example throughout is a fictional ferry operator.

The harness

The open tooling behind the book: ten agent roles, 74 method skills and 31 artefact kinds compiled into host packs, reachable as an MCP server of 29 tools or as a CLI. Every artefact write runs machine-checked acceptance rules, a fact-check replays each evidence citation, and a critic gate sits on the write path. The code, the platform manual and the template catalogue live with the book.

Why it exists

Method as code, with the gates written down

A method specified precisely enough for a machine to run it, a working tool built and documented with AI assistance, and evidence gates on generated output. The employment work under Work is the practice; this is the workshop behind it.
